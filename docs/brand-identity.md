# Sotto brand identity

The UI accent is violet, with distinct light/dark variants.

Sotto uses a rounded white S stroke on a deep violet app tile. The menu bar uses a monochrome template version; inline assistant marks use the same S. Runtime assets live in `Assets/AppIcon.icns`, `Assets/AppIcon-1024x1024.png`, and `Sources/Sotto/Resources/{sotto-mark,menubar-icon,menubar-icon@2x}.png`.

The Parakeet speech engine retains its model name. Archived promotional art and screenshots belong to the original upstream brand and are not runtime Sotto assets. Original authorship and legal notices must remain intact.
